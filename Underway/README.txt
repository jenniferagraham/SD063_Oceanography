This directory contains data and scripts relating to underway sensors on the RRS Sir David Attenborough during the SD063 GIANT cruise. The subdirectory structure is as follows:

--------- Underway --------
---- ancillary
	-- DY158
	-- SD033
	-- SD041
	-- SD063
---- Figures
---- merged_data
---- Salts
---- underway_params_archive
---- Underway_scans_logsheet


Scripts used to query the RVDAS table (more information: https://www.sda.bas.ac.uk/Data_Logging_Systems and in the README.md file in this directory) are in the top-level directory. The script sd063_plot_ocl_simple.m generates simple plots and gridded layouts for underway variables, to allow quick comparison.

"Ancillary data" is empty for SD063.

The "Figures" directory contains the output plots from the script sd063_plot_ocl_simple.m. 

Data files in the "merged_data" directory were generated by the Data Merge Parameter Builder: https://data-merge.sda.bas.ac.uk/. These include the cruise track at 1-day resolution, all underway data for the cruise during science time (i.e. excluding transit) at 5-minute resolution, salinity, sea surface temperature and Uncontaminated Sea Water intake parameters at 5 minute resolution, and additionally hoist position for the UCSW at 1-minute resolution. The data are read by sd063_plot_ocl_simple.m

"Salts" contains the blank log sheet template for recording water samples taken from the underway system.

The directory "underway_params_archive" contains cruise-specific scripts for setting the instrument configuration. the script set_underway_params_sda.m is the general/master code.

"Underway_scans_logsheet" contains a scanned copy of the completed underway sampling logsheet for SD063.
