# SD063 GIANT

The scripts in this repository were used and developed by the Oceanography team on SD063 GIANT: 

* Jennifer Graham (SAMS)
* Laura Castro de la Guardia (SAMS)

* Paul Holland (BAS)

Core scripts for initial data processing were provided from previous BAS cruises. This repository outlines where changes to those were necessary, and also provides scripts that were used for plotting outputs during the cruise, to view initial results and support planning. 

With thanks to all the crew and cruise participants on the RRS Sir David Attenborough.
